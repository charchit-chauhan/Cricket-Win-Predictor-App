### 🏏 Cricket Win Predictor (LSTM)

An AI-powered application that predicts the win probability of a cricket match in real-time using Deep Learning.

## 🚀 Features
- **LSTM Architecture:** Processes match sequences to understand game momentum.
- **Real-time UI:** Built with **Streamlit** for interactive predictions.
- **Dynamic Inputs:** Adjust score, wickets, and overs to see live probability shifts.

## 🛠️ Tech Stack
- **Language:** Python
- **Deep Learning:** PyTorch
- **Data Handling:** Pandas, NumPy, Scikit-learn
- **Frontend:** Streamlit

## 📋 How to Run
1. Clone the repo: `git clone https://github.com/charchit-chauhan/Cricket-Win-Predictor-App.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `streamlit run app/app.py`
